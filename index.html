VERIFY › BEHAVIOUR

Website Behaviour Analysis

Inspect forms, password fields, external form destinations, iframes and script patterns. Unknown page code is never executed — the source is parsed as inert text.

Safe source analyzer (works offline)
Paste the page’s HTML source, or load a saved .html file. It is parsed with the browser’s DOM parser without running scripts, loading images or opening the site.
Remote safe scan (server API)
Fetches the public page from a server boundary (never from your device) and reports status, redirect chain and page structure. Requires the optional /api/page-analysis backend.
Static HTML only. Browser-rendered behaviour (JavaScript-built forms, delayed redirects) needs a sandboxed browser stage.

SYSTEM › PRIVACY
Privacy Center
What stays on your device, what leaves it, and how to switch it off.

  

    
Principles
  • Your location is used only to identify nearby official cybercrime assistance. It is not required to scan a website.
  • Location is requested only when you press the button, uses the browser’s standard permission prompt, is processed locally and is never stored.
  • Passwords, OTPs, PINs and CVVs are never requested. If you type one into chat, it is blocked before sending.
  • Investigation history stays in this browser’s local storage. Complaint drafts are not stored.
  • No analytics, no advertising, no selling or sharing of data.

    
Your controls
Erasing removes history, settings and saved checklist progress from this browser.
